常见问题

Q1. 忘记门禁验证方式了，日记会被清空吗？

不会。半页没有「忘记密码即清空数据」的逻辑。门禁使用的是系统提供的验证方式（Face ID / Touch ID 或设备密码），因此只要你能解锁这台 iPhone，就能打开半页。如果系统本身无法验证，请联系我们，不要直接删除 App —— 删 App 会一并删除本机数据。

Q2. 换手机后日记怎么迁移？

在旧设备打开「设置 → 数据 → 导出全部」，选择 JSON 备份，把文件保存到「文件」App 或任意云盘；在新设备打开「设置 → 数据 → 导入备份」，选择该文件即可。导入时可选择「覆盖同 ID 记录」或「追加为副本」。照片不随备份迁移（备份文件只包含文字内容），如需保留照片请在旧设备上单独留存。

Q3. 数据存在哪里？会丢吗？

全部保存在这台设备的 App 沙盒内。我们不做自动云同步，因此：卸载 App 会删除本机数据；建议定期导出备份，并把备份文件放到你信任的位置（如 iCloud Drive、电脑）。

Q4. 为什么没有自动云同步？

出于隐私定位，v1.0 采用「本地优先 + 显式备份」的方案：内容不由我们上传到任何服务器，换设备由你主动导出导入。这样做的代价是多一步手动操作，收益是你不必相信任何第三方会保管好你的日记。

Q5. 免费版有什么限制？付费后我的内容会变吗？

免费版最多可写 30 篇，其余功能（门禁、照片、日历、回顾、导出）全部可用。达到上限后不会删除或隐藏任何内容，只是新增时会提示解锁永久版。永久版为一次性买断，不存在订阅与自动续费。

Q6. 换了新手机，永久版还要再买一次吗？

不用。进入「设置 → 解锁永久版 → 恢复购买」，使用当初购买时的同一个 Apple ID 即可恢复，无需重复付费。恢复购买需要联网。

Q7. 怎么申请退款？

所有付款由 Apple 处理，退款需通过 Apple 渠道申请：访问 reportaproblem.apple.com，或在 iPhone「设置 → Apple ID → 购买记录」中找到对应订单申请。退款由 Apple 审核决定，与我们无关；无论退款是否通过，你已写的内容都不会被删除或锁定。

Q8. 误删了日记还能找回吗？

可以。删除的日记会进入「设置 → 数据 → 最近删除」，保留 30 天，期间可随时恢复。也可以在「最近删除」里手动清空，清空后无法恢复。

Q9. 支持 Markdown 吗？

支持。在「设置 → 外观」打开「Markdown 纯文本模式」，正文会使用等宽字体，并可切换到预览，渲染标题、列表、引用、待办、粗体与代码。

Q10. 支持 iPad、Apple Watch 或 Mac 吗？

当前版本支持 iPhone（iOS 17 及以上）。iPad 与桌面端在后续版本的规划中，欢迎邮件告诉我们你的需求优先级。

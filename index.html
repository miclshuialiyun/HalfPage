半页是一款把「减法」做到底的日记工具。它不要求你写满一页，不逼你连续打卡，不上传你的任何内容。你只需要在想到的时候打开它，写下半页，然后锁上。

核心能力

✍️

极简编辑器

标题、正文、心情、照片，四件事就能写完一篇。没有复杂工具栏，没有打卡压力。

🔒

生物识别门禁

用 Face ID / Touch ID 或设备密码才能打开。切到后台超过设定时长会自动重新上锁。

🖼️

照片加密存储

插入的照片以 AES-GCM 加密后存储在 App 沙盒内，并启用系统文件保护。

🌤️

心情与天气

六种心情、六种天气，图标与文字并存，不靠颜色单独传达信息，色觉障碍同样可用。

📅

日历与时间轴

按月回看，每天的心情在日历上留下一个色点。写了几天、什么时候断过，一目了然。

📊

本地统计回顾

连续天数、最长连续、7 日写作天数、心情分布与 12 周热力图，全部在设备上计算。

🔍

全文检索

标题、正文、标签一起搜，本地即时返回，不需要联网、不上传关键词。

📝

Markdown 纯文本模式

喜欢纯文本的人可以把编辑器切成等宽字体与 Markdown 预览，标题、列表、引用、待办都能渲染。

📤

数据可导出

Markdown、纯文本、JSON 备份三种格式，随时导出、随时带走，换设备导入即可继续写。

🗑️

删除可反悔

删除的日记先进「最近删除」，30 天内可以恢复；也可以随时彻底清空。

界面一瞥

四个界面构成完整闭环：写下 → 标记心情 → 日历回看 → 回顾趋势。

我们的三条原则

1

不上传

没有账号、没有服务器、没有第三方统计 SDK。半页不发起任何内容上传请求。

2

不打扰

没有广告、没有推送营销、没有诱导分享。写与不写，都由你自己决定。

3

一次买断

没有订阅、不会自动续费。免费版可写 30 篇，永久版解锁后不再受限。

隐私怎么做的，说清楚

我们不使用「无法被任何人读取」这类无法兑现的说法。半页 v1.0 的隐私保护由三部分组成：

  • 门禁：开启后需通过 Face ID / Touch ID 或设备密码才能进入 App 内容；
  • 系统文件保护：日记数据库文件设置为「首次解锁后才可访问」，锁屏状态下不可读；
  • 照片加密：照片以 AES-GCM 加密后写入 App 沙盒，密钥保存在本机钥匙串、不随 iCloud 钥匙串同步。

需要特别说明：日记正文由系统文件保护与应用沙盒保护，并未做逐条端到端加密。如果你的威胁模型更严格，建议同时开启门禁并关闭 iCloud 备份中的本 App 数据。
